# Airline Management System

A web application for managing airline operations: passenger records, flight schedules, ticket booking and cancellation.

## Features
- Add and view passenger records
- Manage flight schedules and flight information
- Book and cancel tickets
- Data stored in a Supabase (SQL) database

## Tech Stack
React, TypeScript, Vite, Supabase, Tailwind CSS

## How to Run
1. Install Node.js (version 20 or higher)
2. Clone the repo: `git clone https://github.com/ssanika589-del/Airline-Management-System.git`
3. Go into the folder and run: `npm install`
4. Create a `.env` file with your own Supabase details:
   VITE_SUPABASE_URL=your_url_here
   VITE_SUPABASE_ANON_KEY=your_key_here
5. Start the app: `npm run dev`
